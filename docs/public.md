`forge` — утилита командной строки для CI/CD-интеграции с инфраструктурой через Vault и шаблоны конфигурации.

Что делает `forge`:
- хранит и версионирует данные окружений в HashiCorp Vault;
- генерирует финальный YAML из Go-шаблонов;
- поддерживает шаблоны с Go template-переменными и вложенной структурой данных окружения;
- умеет обновлять и создавать стеки через Portainer API (`forge deploy stack file|template|refresh ...`).

Подробная документация по настройке и командам находится в разделе [Документация](README.md).
